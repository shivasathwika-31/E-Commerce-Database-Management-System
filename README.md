# E-Commerce Database Management System

## 📌 Project Overview

This project is a complete SQL-based E-Commerce Database Management System developed using MySQL.

The system manages customers, products, categories, suppliers, orders, order details, and payments. It demonstrates relational database design and advanced SQL concepts used for business data analysis.

## 🎯 Objectives

- Design a structured relational database for an e-commerce platform
- Manage customer, product, order, supplier, and payment information
- Perform business analysis using SQL queries
- Implement advanced database features
- Generate useful insights from e-commerce data

## 🗂️ Database Tables

- Customers
- Categories
- Products
- Suppliers
- Orders
- OrderDetails
- Payments
- StockHistory

## 🛠️ SQL Concepts Used

- Primary Keys and Foreign Keys
- Constraints
- INSERT, UPDATE, DELETE, SELECT
- JOINs
- Aggregate Functions
- GROUP BY and HAVING
- Views
- Stored Procedures
- Triggers
- Indexes
- Window Functions
- Business Analysis Queries

## 📊 Business Analysis Performed

- Customer spending analysis
- Product sales and revenue analysis
- Category-wise revenue analysis
- Daily sales performance
- Low-stock product analysis
- Payment status analysis
- Best-selling product analysis
- Order status analysis

## 🔍 Key Insights

- Electronics generated the highest category revenue.
- Laptop generated the highest revenue among individual products.
- T-Shirt had the highest quantity sold.
- Low-stock products were identified for inventory management.
- Delivered orders contributed the highest order value.
